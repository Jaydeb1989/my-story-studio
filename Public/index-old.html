🌹 My Story Studio

दो reference photos से कहानी के अलग-अलग cinematic scenes बनाइए

1. Character Reference Photos

ये फोटो इसी ब्राउज़र में सेव रहेंगी। हर scene के साथ server को भेजी जाएँगी। साफ, सामने से ली गई फोटो बेहतर रहती है। फोटो 12 MB से कम रखें।

अभी reference photos सेव नहीं हैं।

2. Image Settings

API Key इस HTML में नहीं रखी जाती। इसे केवल hosting server की Environment Variable OPENAI_API_KEY में डालना है।

नीचे 20 sample romantic scenes दिए हैं। हर scene का prompt बदल सकते हैं।

पहले दोनों reference photos सेव करें, फिर scene generate करें।
